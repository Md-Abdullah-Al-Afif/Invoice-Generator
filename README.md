# Invoice Generator

A modern and responsive invoice generator that allows users to create professional invoices with real-time preview, customizable branding, and instant PDF export.

Designed with a clean user interface and built using modern frontend technologies, this project demonstrates component-based development, state management with React Hooks, and responsive UI design.

---

## ✨ Features

- 📄 Create professional invoices
- 👤 Sender and client information management
- 📦 Dynamic line item management
- ➕ Add or remove invoice items
- 💰 Automatic subtotal, tax, discount, and total calculations
- 🎨 Multiple built-in color themes
- 🌈 Custom brand color selection
- 🖼 Company logo upload
- 💱 Multiple currency support
- 📅 Invoice and due date selection
- 📝 Notes and payment terms
- 👀 Real-time invoice preview
- 🖨 Print or Save as PDF
- 📱 Fully responsive design

---

## 🛠 Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/Md-Abdullah-Al-Afif/Invoice-Generator.git
```

Go to the project folder

```bash
cd invoice-generator
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Open

```
http://localhost:5173
```
